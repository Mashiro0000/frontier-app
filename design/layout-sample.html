Find the best month in this file, and give me a short script to check it myself.
Claude Opus 5.5
Read sales.csv in your workspace

March was your best month: $42,300, which is 18% above February.

This script adds up each month and prints the top one:

python 
import csv
from collections import defaultdict

totals = defaultdict(float)
with open("sales.csv", newline="") as f:
    for row in csv.DictReader(f):
        totals[row["month"]] += float(row["amount"])

best = max(totals, key=totals.get)  # the month with the largest total
print(f"Best month: {best} (${totals[best]:,.0f})")

Run it in the folder that holds sales.csv.
